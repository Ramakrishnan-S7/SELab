## Dependencies Explained

The Rust project has **minimal dependencies** (as per SRS requirement):

### Required
- **nix** (~0.27) - Linux syscalls (epoll, setsockopt)
  - Used for: `poll()`, `PollFd`, `setsockopt`
  - Why: Direct Linux epoll API
  
- **libc** (~0.2) - C types and functions
  - Used for: Basic C interop
  - Why: Needed by nix crate

### Standard Library
- Everything else uses Rust std library
- No web frameworks (Express, Actix, etc.)
- No async runtimes (tokio, async-std)
- No heavy protocols (HTTP, gRPC)
- Pure blocking I/O with epoll

## Common Issues & Solutions

### Issue: "Cannot find module `protocol`"
**Solution**: Make sure `src/main.rs` has `mod protocol;` and `mod ingestion;`

### Issue: "Command not found: cargo"
**Solution**: Install Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

### Issue: "Permission denied binding to port 8080"
**Solution**: Either use port > 1024, or run with sudo (not recommended)

### Issue: "No data received" from edge_streamer
**Solution**: 
1. Verify edge_streamer is running
2. Check daemon is bound: `netstat -ul | grep 8080`
3. Check firewall: `sudo ufw status`

### Issue: Tests fail with network errors
**Solution**: Some integration tests require clean port binding. Try:
```bash
cargo test -- --test-threads=1
```
